Milwaukee Flood Risk

Building a Composite Index usng Open-Source Methods

About

As part of my efforts to improve my open-source geospatial skills, I decided to build a simple composite score to assess flood risk in a given area. For this project, I chose Downtown Milwaukee. I used SQL queries to download 3 years of storm events from NOAA, flood zone data from FEMA, and building and water data from Overture.

I then built a python notebook to conduct my analysis, creating a score from 0-100 for each hex bin in my bounding box. I then created a a composite score which weighted and combined each variable to create a more holistic understanding.

Finally, after converting the output geojson into pmtiles using tippacanoe, I built a html file to visualize my data as maps with pop-ups and captions. Feel free to scroll below to see the final maps, and for a more in depth explanation, you can access the github repo here:
